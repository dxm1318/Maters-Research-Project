# Masters Research Project

**University of Miami** | M.S. in Music Engineering and Technology

This repository contains the MATLAB code and paper for a masters research project on parameter optimization of the Synchronized Swept Sine (SSS) technique for the separation and extraction of distortion product otoacoustic emissions (DPOAEs).

---

## Overview

Distortion product otoacoustic emissions are sounds generated by the inner ear in response to two simultaneous pure tones. The Synchronized Swept Sine technique allows these emissions to be separated into their short-latency (SL) and long-latency (LL) components. This project systematically investigates how three key parameters of the SSS technique affect the quality of that separation, evaluated through three metrics:

- **Temporal Separation** — latency difference between SL and LL components
- **Overlap %** — degree of overlap between SL and LL components
- **SNR** — signal-to-noise ratio of the short-latency component

The three parameters under investigation are:

| Parameter | Description |
|-----------|-------------|
| `r` | Sweep rate of the synchronized swept sine |
| `alpha` | Amplitude parameter |
| `stim` | Stimulus level |

A copy of the full paper is included in the repository: `Martens, Daniel_Research Project.pdf`

## Getting Started

### Running the Simulations (Quick Start)

The preprocessed datasets are already included in the `Simulation Code/` folder. To run the simulations directly:

1. Open MATLAB and navigate to the `Simulation Code/` directory.
2. Load the desired dataset into the workspace:
   ```matlab
   load('PreGenerated_OAE_R.mat')     % for sweep rate parameter
   load('PreGenerated_OAE_Alpha.mat') % for alpha parameter
   load('PreGenerated_OAE_Stim.mat')  % for stimulus level parameter
   ```
3. Run the corresponding simulation script:
   ```matlab
   r_sim       % sweep rate simulation
   alpha_sim   % alpha simulation
   stim_sim    % stimulus level simulation
   ```

### Running the Preprocessing (Optional)

Only necessary if you want to regenerate the DPOAE datasets from scratch.

1. Navigate to the `Preprocessing Code/` directory.
2. Start the Auditory Modeling Toolbox:
   ```matlab
   amt_start
   amt_mex
   ```
   If no errors appear, the toolbox is ready.
3. Run the desired generation script:
   ```matlab
   OAE_data_r      % generates PreGenerated_OAE_R.mat
   OAE_data_alpha  % generates PreGenerated_OAE_alpha.mat
   OAE_data_stim   % generates PreGenerated_OAE_Stim.mat
   ```
   Each script generates 10 unique DPOAEs per parameter value using the `verhulst2012` cochlear model.

## Pipeline Overview

### Preprocessing

```
Parameter range (loop)
  └─ For each parameter value (nested loop × 10 trials)
       └─ SSS_gen.m + synchronized_swept_sine.m  →  generate swept sines
       └─ get_OAE.m + verhulst2012.m             →  simulate DPOAE response
  └─ Save as .mat file
```

### Simulation

```
Load .mat dataset
Parameter range (loop)
  └─ For each DPOAE in dataset
       ├─ VIR_deconv.m + synchronized_swept_sine_spectra.m   →  deconvolve
       ├─ synchronized_swept_sine_IR_separation.m             →  separate distortion products
       └─ For each distortion product
            ├─ separate_SL_LL.m                              →  isolate SL and LL components
            └─ compute_metrics.m                             →  temporal separation, overlap %, SNR
└─ organize_results_*.m   →  export .csv files
└─ Plots: parameter vs. each metric
└─ 2-way ANOVA: parameter effect, DP type effect, and their interaction
```
